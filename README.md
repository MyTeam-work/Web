- قرارداد و معماری: [`SPEC.md`](SPEC.md)
- جریان کار و قوانین: [`WORKFLOW.md`](WORKFLOW.md)
- مرجع فنی پلتفرم: [`docs/tgcloud-sdk.md`](docs/tgcloud-sdk.md)
- مالکیت فایل‌ها: [`.github/ownership.json`](.github/ownership.json)
- بررسی خودکار قوانین: [`.github/workflows/rules.yml`](.github/workflows/rules.yml)

هر نفر روی شاخه `work/<name>` کار می‌کند و با PR به `main` می‌رود.
