# AGENTS.md

Telegram Mini App fashion shop on Telegram Serverless (tgcloud). Bot: @MiniShop_Afbot.

Read order for any AI agent working here:

1. `docs/team/<your-name>.md` - your files, skills and prompt.
2. `SPEC.md` - the contract (schema, endpoints, lib signatures, flows).
3. `docs/tgcloud-sdk.md` - platform rules.
4. The newest Handoff addressed to you in `WORKFLOW.md`.

Do not scan other files. Trust the contracts in SPEC.md. Edit only your own files (see `.github/ownership.json`). Never run `tgcloud push` or `tgcloud migrate`; never commit tokens.
